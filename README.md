# アマチュア無線 フォネティック・モールスコードトレーナー

NATO/JSARLフォネティックコードとモールス信号を同時練習できる4アマ・3アマ試験対策ツール。

## 特徴

- フォネティック一覧（NATO・JSARL日本語版）をモールス付きで表示
- Web Audio APIによるモールス符号音声再生（速度5〜30 WPM調整可）
- 4択クイズ：モールス→文字・文字→モールス・フォネティック→文字の3モード
- コールサイン入力で各文字のフォネティック+モールス変換表示
- 正答率・連続正解履歴の統計表示

## 技術

- Web Audio API（OscillatorNode）でリアルタイムモールス音声生成
- WPM（Words Per Minute）に基づく符号長計算
- localStorage不使用（セッション内統計のみ）
